# 星光故事屋

《AIGC应用开发实践》课程主线项目。当前版本完成了第1周“作业0：个性化儿童故事网页”。

用户填写主角姓名、年龄和兴趣，再从勇气、友谊、环保三个主题中选择一个，网页会在本地生成专属儿童故事。

## 在线体验

访问地址：<https://woqu6333-prog.github.io/aigc-story-project/>

## 当前功能

- 支持主角姓名、年龄、兴趣三个个性化参数
- 支持“勇气冒险”“友谊成长”“自然守护”三种主题
- 不同主题具有不同故事内容和视觉配色
- 对空输入和年龄范围进行校验
- 支持重新生成、复制故事、下载 TXT
- 自动保存最近一次输入和故事
- 支持电脑和手机尺寸
- 完全离线运行，不上传用户信息，不产生 API 费用

## 快速运行

### 方法一：直接打开

进入 `dist/` 目录，双击 `index.html`。

### 方法二：本地服务器运行

在项目根目录执行：

```bash
python -m http.server 8000 -d dist
```

然后访问：

```text
http://localhost:8000
```

## 使用方法

1. 输入主角名字，例如“小雨”。
2. 输入3～12岁的整数年龄。
3. 输入一种兴趣，例如“恐龙”或“画画”。
4. 选择一个故事主题。
5. 点击“生成我的故事”。
6. 可以换一个故事、复制全文或下载 TXT。

## 项目结构

```text
aigc_story_project/
├─ src/web/                  # 作业0网站源码（唯一编辑位置）
│  ├─ index.html
│  └─ assets/
│     ├─ style.css
│     └─ app.js
├─ dist/                     # 可直接运行和提交演示的静态网站
├─ scripts/
│  └─ build_static.py        # 将src/web同步到dist
├─ tests/
│  └─ test_homework0.py
├─ docs/homework0/
│  ├─ ai-log.md
│  ├─ demo-script.md
│  └─ test-report.md
├─ outputs/                  # 后续作业生成的故事、图片、音频和视频
├─ requirements.txt
└─ README.md
```

修改 `src/web/` 后，执行以下命令重新生成 `dist/`：

```bash
python scripts/build_static.py
```

## 运行测试

本项目测试只使用 Python 标准库：

```bash

```
