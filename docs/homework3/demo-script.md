# 作业3演示讲稿（约2分钟）

大家好，这是我的《小雨和月光脚印》多角色有声书，也是前两次作业的继续。

首先看成果：完整音频时长8分57秒，超过3分钟要求，共有旁白、小雨、月光知更鸟和蓝蓝4个角色，每个角色使用不同音色。

这里是同步有声书网页。点击播放以后，网页会根据JSON时间轴自动高亮当前台词，并显示角色和情感。也可以直接点击任何一句，从对应时间开始播放。进入不同章节时，左侧场景图也会跟着变化。

接着看脚本数据。每段台词都包含角色、情感、正文和停顿时间。情感共有平静、温柔、好奇、低语、紧张、思考、兴奋、坚定和安心9种。因为免费 Edge TTS 没有给所有中文声音提供统一的情感标签接口，我用语速、音高和音量的组合表达情感，并在音色映射表里记录了所有参数。

工程上，我先逐段生成并缓存音频，再用 FFmpeg 统一为 WAV，最后用 lameenc 输出标准 MP3。这样避免了直接拼接 MP3 导致的时长和同步误差。程序还会自动检查至少3种音色、分段连续性和最终时长。

这个作业与前面的故事网页和网页绘本都在同一个网站里，形成“输入创意、生成结构化故事、查看绘本、播放有声书”的连续流程。下一步作业4会复用现有插画、音频和时间轴，合成带字幕的故事视频。
