## 实际调试记录

1. 最初尝试使用 `pydub` 拼接，但 Python 3.13 环境缺少旧版 `audioop` 模块，无法稳定运行，因此改用 FFmpeg。
2. 电脑上的 Trae 内置 FFmpeg 是精简版，不支持生成静音所需的 `lavfi`，随后改用剪映目录中的 FFmpeg。
3. 剪映 FFmpeg 的 `mp3_mf` 编码器能写出全部声音，但文件头错误地显示为2分45秒，和实际8分多钟不一致。
4. 最终方案是用 FFmpeg 把所有片段统一为24kHz单声道 WAV，再用 `lameenc` 输出标准128kbps MP3。成品被识别为8分57秒，并通过完整解码检查。
5. 直接累加小 MP3 的时长会包含编码延迟，导致同步时间轴末尾偏差约25秒。改用 WAV 帧数计算后，最后一句与成品末尾仅保留约1.25秒的设计停顿。

这些失败和修正均属于真实开发过程，保留在日志中便于答辩说明工程问题如何定位。

## 当前反思

免费 TTS 可以快速建立完整工程链路，但“情感”主要依赖参数模拟，不等同于专业配音演员或带风格控制的商业情感语音模型。分角色、分段缓存和可追溯时间轴提高了可修改性；后续若替换更好的 TTS，只需要保持脚本和时间轴接口，不必重写网页。
