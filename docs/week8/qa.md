# 答辩高频问题

## 1. 为什么不全部使用云端最强模型？

课程项目需要稳定现场演示，也要控制学生成本。因此核心流程提供离线或免费方案，云API和真实CLIP作为可插拔增强，而不是唯一运行条件。

## 2. 作业0到6真的有关联吗？

有关联。作业1的JSON供作业2使用；作业2图片和作业3时间轴供作业4使用；作业5沉淀可复用素材；作业6把检索、写作、配图、TTS和视频工具串成完整流程。

## 3. 你的Agent和普通流水线有什么区别？

它有显式计划、共享状态、自然语言中途干预、旧成果失效机制和逐工具执行日志。当前规划器是确定性的，优点是免费、稳定、可复现；未来可替换成LLM规划器。

## 4. 图像真的用了CLIP吗？

当前提交默认结果没有冒充CLIP。本机环境缺少PyTorch/OpenCLIP，所以演示索引使用视觉语义标签与TF-IDF。仓库提供真实OpenCLIP编码类，安装依赖和权重后可替换。这是项目目前最明确的技术欠账。

## 5. AI生成比例是多少？

当前代码和文档大部分由Codex辅助生成，约90%左右；学生提供需求、方案取舍并负责理解、测试、展示和后续调整。每个作业的日志分别记录，比例不是为了“好看”而缩小。

## 6. 角色一致性怎么做？

先建立角色设定卡，把发型、服装、颜色和标志物写成固定锚点；各场景只改变动作、表情、镜头和环境，并在提示词中加入负面约束。

## 7. 如果现场网络断开怎么办？

首页离线故事、绘本、已生成音频、视频、素材库和Agent案例都在dist目录，可由本地HTTP服务器运行。只有现场重新调用云LLM或Edge TTS需要网络。

## 8. MiniMax H3为什么没有使用？

本地H3生成视频耗时较长，不适合作为每次回归测试和现场必经流程。本阶段用FFmpeg完成确定性视频合成。H3可作为后续画面质量增强，不影响现有架构。
