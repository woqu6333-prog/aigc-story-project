# 星光故事屋课程项目总结

## 项目目标

围绕儿童故事创作，将文本生成、图像、语音、视频、检索与Agent逐周整合，形成可演示、可复现、可继续扩展的AIGC产品。

## 技术路线

- 前端：原生HTML/CSS/JavaScript，保证零构建依赖与GitHub Pages兼容
- 文本：OpenAI兼容API + Pydantic结构校验 + 离线演示
- 图像：角色锚点提示词、程序化素材图、可选扩散模型替换
- 音频：Edge TTS、情感参数、多角色时间轴
- 视频：FFmpeg、H.264/AAC、字幕图层、原创程序化音乐
- 检索：中文TF-IDF、同义词扩展、余弦相似度、可选OpenCLIP
- Agent：LangChain Core StructuredTool、确定性规划、共享状态与人工干预
- 工程：unittest、静态构建、环境变量、Git/GitHub Pages

## 核心成果

项目实现了从一个故事创意到多模态成果的完整链路。作业5包含59条可检索素材，作业6有5个工具和2套真实完整案例。所有阶段均提供README和AI协作日志。

## 已知局限

1. 未配置云API时，作业1离线故事文学性有限。
2. 作业5默认后端不是真实CLIP，虽然接口已提供。
3. 作业6规划是规则驱动，不具备开放式LLM推理能力。
4. Agent案例配图是程序化插画，画面质量低于扩散模型。

## 后续改进

优先顺序是：配置免费云文本API并重新完成Prompt实测；在独立GPU环境建立真实CLIP索引；将作业2图像模型接入Agent；最后把MiniMax H3作为可选高质量视频工具，而不是现场演示的必经步骤。
