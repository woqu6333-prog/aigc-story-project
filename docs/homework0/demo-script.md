# 作业0演示视频讲稿

目标时长：约1分40秒，最长不超过2分钟。

## 0:00–0:15 项目介绍

大家好，这是我的《AIGC应用开发实践》作业0——“星光故事屋”。它可以根据孩子的姓名、年龄、兴趣和主题，在本地生成个性化儿童故事。

## 0:15–0:38 输入信息

页面左侧是创作卡片。我输入主角“小雨”，年龄7岁，兴趣是“恐龙”。系统目前支持勇气冒险、友谊成长和自然守护三个主题。选择主题时，页面配色也会同步变化。

## 0:38–1:02 生成故事

我先选择“勇气冒险”，点击“生成我的故事”。右侧会出现故事标题、人物信息、分段正文和故事寓意。可以看到，姓名、年龄和兴趣都进入了故事内容，而不只是显示在标题里。

## 1:02–1:22 主题和交互展示

点击“换一个”可以生成不同情节。重新选择“自然守护”后，故事内容和页面颜色都会改变。页面还支持复制全文和下载TXT，方便保存故事。

## 1:22–1:40 技术与总结

项目使用HTML、CSS和JavaScript实现，不依赖后端或网络，电脑和手机都可以使用。我还增加了输入校验、本地保存和自动测试。下一周会把模板生成升级为大模型API生成结构化JSON故事。谢谢大家。

## 录屏清单

- 浏览器不要显示无关标签页或私人信息。
- 开始前清空或准备好演示输入。
- 展示至少两种主题，最好快速带到第三种主题。
- 点击一次“换一个”。
- 展示复制或下载中的一个即可，避免超时。
- 录制完成后检查声音、画面和总时长。
