# 作业4视频生成与剪辑流程说明

## 路线选择

课程提供“生成式”和“剪辑式”两条路线。本作业选择剪辑式：用Python组织数据，用FFmpeg完成音画处理，用Pillow生成中文片头、片尾和字幕图层。

选择原因：

- 已有角色一致的高质量绘本图和完整配音，可以直接复用；
- 本地视频生成模型耗时较长，不适合频繁调试；
- 剪辑式流程可重复、可测试，现场演示更稳定；
- 每个字幕时间都能追溯到JSON时间轴，便于解释音画同步。

## 素材对应关系

| 来源 | 复用内容 | 作业4用途 |
| --- | --- | --- |
| 作业1 | 故事结构与寓意 | 决定视频叙事顺序和片尾主题 |
| 作业2 | 3幅横版角色一致绘本图 | 作为全部视频画面 |
| 作业3 | 多角色MP3、逐段时间轴 | 截取旁白和对白，生成字幕 |
| 作业4脚本 | 原创背景音乐、镜头和字幕 | 自动合成最终MP4 |

## 时间轴设计

视频先播放4秒片头，再依次使用作业3的第1、3、7、8、17、22、30段台词。相邻片段之间保留0.6秒呼吸间隔，最后加入5秒主题片尾。

选择这些片段是为了在较短时间内保留完整结构：

1. 雨后月光森林的环境；
2. 小雨发现奇怪脚印；
3. 知更鸟请求帮助；
4. 小雨决定寻找同伴；
5. 找到被困的小蓝鸟；
6. 蓝蓝重新展开翅膀；
7. 旁白总结“真正的勇气”。

## 字幕同步

每段字幕正文直接取自作业3脚本。程序先按中文标点拆分，再把该段配音总时长按每个字幕的有效字数比例分配。字幕被渲染为透明PNG，包含：

- 当前角色；
- 情感标签；
- 当前台词。

合成时，FFmpeg根据每条字幕的 `start` 和 `end` 精确控制显示范围。由于字幕已经烧录到视频画面，即使脱离网页或没有额外字幕文件也能正常观看。

## 画面运动

静态绘本图通过FFmpeg `zoompan` 滤镜产生缓慢推近与水平移动。所有镜头统一为1280×720、24fps和相同像素格式，然后拼接，避免不同素材参数导致卡顿。

## 声音处理

- 配音：根据作业3时间轴，用 `atrim` 精确截取源MP3；
- 音乐：Python使用正弦波和四组和弦本地生成，无外部版权素材；
- 混音：配音保持原音量，音乐降低到19%，片头淡入、片尾淡出；
- 检测结果：平均音量约-21.9dB，峰值约-3.2dB，没有削波。

## 编码与验证

本机检测到NVIDIA编码能力，因此使用 `h264_nvenc` 生成H.264视频，并用AAC 192kbps保存声音。成品通过以下检查：

- FFmpeg从头到尾完整解码无错误；
- Mutagen检测时长为约138.19秒；
- 5个关键时间点抽帧检查片头、字幕、中段、结尾和片尾；
- 自动测试检查时长、分辨率计划、字幕数量和网站构建产物。
