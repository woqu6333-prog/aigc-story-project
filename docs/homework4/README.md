# 作业4：故事短视频自动剪辑

## 作业成果

本作业采用课程给出的方案B（剪辑式），把作业2绘本图片、作业3多角色配音和JSON时间轴自动合成为故事短视频，不使用耗时的 MiniMax H3 视频模型。

| 指标 | 实际成果 |
| --- | --- |
| 视频标题 | 《小雨和月光脚印》故事精华 |
| 实际时长 | 2分18秒（课程要求至少60秒） |
| 分辨率 | 1280×720 |
| 帧率 | 24fps |
| 视频编码 | H.264（本机NVIDIA NVENC） |
| 音频编码 | AAC 192kbps |
| 画面 | 3幅作业2绘本图、片头、片尾、缓慢推拉镜头 |
| 配音 | 从作业3成品按时间轴精确截取7段关键台词 |
| 背景音乐 | Python本地生成的原创轻音乐，无版权素材依赖 |
| 字幕 | 41段烧录字幕，包含角色名和情感标签 |

主要交付物：

- `outputs/video/homework4/xiaoyu-story-video.mp4`：最终视频；
- `outputs/video/homework4/thumbnail.jpg`：视频封面；
- `outputs/video/homework4/video-plan.json`：镜头、字幕、时间和编码信息；
- `src/story_video/builder.py`：完整自动剪辑逻辑；
- `scripts/generate_video.py`：一键生成入口；
- `src/video_web/`：作业4展示网页。

## 重新生成

确认作业2图片和作业3音频存在，然后执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\generate_video.py
.\.venv\Scripts\python.exe scripts\build_static.py
```

脚本优先选择本机 `h264_nvenc` 显卡编码器；若不可用，会自动尝试 `h264_mf`，最后回退到软件 `mpeg4`。生成过程不调用收费API。

## 自动剪辑流程

```text
作业2三幅绘本图
        +
作业3有声书MP3与timeline.json
        ↓
选取7段关键台词并按源时间精确截取
        ↓
生成片头、片尾与缓慢推拉镜头
        ↓
按标点与字数把台词拆为41个字幕片段
        ↓
本地生成原创和弦背景音乐
        ↓
配音 + 音乐混合，字幕图层逐段叠加
        ↓
H.264画面 + AAC声音 → MP4
```

详细技术说明见 [`workflow.md`](workflow.md)。
