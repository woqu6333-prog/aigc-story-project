# 作业4演示讲稿（约2分钟）

大家好，这是我的作业4《小雨和月光脚印》故事精华短视频。

我选择的是课程里的方案B，也就是用代码把前几周的图片和音频自动剪辑成视频。最终成品时长2分18秒，分辨率1280乘720，24帧，包含画面、多角色配音、原创背景音乐和烧录字幕。

先播放一小段。可以看到静态绘本图经过缓慢推拉后有了镜头运动，字幕会显示当前角色、情感和台词。字幕不是我手工逐条输入时间，而是直接读取作业3的JSON时间轴生成，因此台词内容和配音来源一致。

再看代码流程。程序从8分57秒有声书中选取7段关键情节，用FFmpeg按照起止时间精确截取；然后用Pillow生成片头、片尾和41个透明字幕图层；背景音乐由Python本地合成，不使用外部版权素材；最后把画面、配音、音乐和字幕混合为H.264与AAC格式的MP4。

这个视频复用了作业1的故事结构、作业2的角色一致图片和作业3的多角色配音与时间轴，所以不是几个独立作业，而是一条连续的生产流程。

我没有在本次使用本地H3视频模型，因为生成耗时较长，而课程允许代码剪辑路线。未来可以让H3只生成少量关键动态镜头，再放回现有自动剪辑流程，提高画面表现，同时保留当前稳定的字幕和音频同步。
