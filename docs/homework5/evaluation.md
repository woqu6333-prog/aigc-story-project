# 多模态检索评估

## 方法

- 查询数：3
- 主要指标：图像结果 Precision@5
- 判定：Top 5图像的标签是否命中该查询的人工相关标签
- 原始结果：`outputs/library/homework5/evaluation.json`

## 结果

| 查询 | 预期概念 | Precision@5 |
| --- | --- | ---: |
| 女孩乘火箭去太空冒险 | 太空、火箭、星球 | 0.80 |
| 森林里的小鸟友谊故事 | 森林、小鸟、友谊 | 0.80 |
| 海底鲸鱼保护珊瑚 | 海底、鲸鱼、珊瑚、环保 | 0.80 |
| **平均** | — | **0.80** |

## 分析

优势是少量中文素材也能得到稳定、可解释的结果，同义词“宇宙/太空”“海洋/海底”能够互相召回。局限是默认图像排序依赖人工视觉标签，无法像CLIP一样自动理解未标注的画面细节。后续切换真实OpenCLIP时，应保留这3组查询作为回归集，并增加无标签图像测试。
